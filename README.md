# PCL Download Patch

恢复 PCL（Plain Craft Launcher）新版本中被关闭的 Minecraft 下载与整合包安装功能。

> 官方在新版启动器中关闭了 MC 下载与整合包安装（提示"为遵守相关法律法规……qwq"）。
> 本工具通过修改**你电脑上**的启动器文件来恢复这些功能——不包含、也不分发任何 PCL 程序代码或文件。
>
> **本项目为非官方第三方项目，与 PCL 官方及作者龙腾猫跃无任何隶属或背书关系。**

## 恢复的功能

- MC 版本下载：原版 / Forge / Fabric / NeoForge 等（具体可选列表由启动器内置的版本清单决定）
- 整合包安装：CurseForge / Modrinth（.mrpack）/ MCBBS / HMCL / MMC / 带启动器压缩包
- 版本修改页的 MC 选择卡片

## 运行环境

- **Windows**（补丁器依赖 .NET 与 PowerShell）
- 自带 PowerShell 即可，无需额外安装；若系统有 PowerShell 7（`pwsh`）会自动优先使用

## 使用方法

1. 从 [最新 Release](../../releases/latest) 下载 `PCL-Download-Patch-vX.X.X.zip` 并解压到任意位置
2. 从官方渠道获取启动器：
   - 正式版（免费）：[meloong.com/pcl](https://meloong.com/pcl)
   - 快照版（赞助）：使用你自己的爱发电赞助账号下载

### 方式一：图形界面（推荐）

双击 **「打开补丁界面.vbs」**，界面上：

1. 把 `Plain Craft Launcher 2.exe` 拖进窗口，或点「浏览…」选择
2. 选择更新后的自动修复方式（常驻守护 / 启动壳检测 / 不自动修复）
3. 可选勾选「打补丁前复制一份备份到同目录」
4. 点「开始打补丁」

界面上还有两个按钮：
- **启动PCL** — 走「启动壳检测」逻辑，启动前自动检查并修复
- **卸载补丁** — 一键还原启动器并移除开机自启守护

> 打补丁时会在补丁包内静默保留一份原始 exe（约 6MB），供「卸载补丁」完整还原。
> 如果不需要卸载功能，可点界面上的「清理原始备份」释放空间。

### 方式二：拖放 bat

把 `Plain Craft Launcher 2.exe` 拖到下面任意一个 bat 上松手：

- **「拖我上去.bat」**：按菜单选择更新后的自动修复方式
- **「拖我上去_常规版.bat」**：只打补丁，不安装任何自动修复

包内还附带 `使用说明.txt`，是同样内容的纯文本版本。

## 谁需要打补丁

| 启动器 | 是否需要 |
| --- | --- |
| 新版正式版（官方已限制下载的构建） | 需要 |
| 快照版（赞助版） | 需要 |
| 旧版正式版（官方未限制下载的构建，如 2.13.1.1） | 无限制，无需补丁 |

补丁器会自动判断；也支持**自动修复旧版本补丁包留下的已知缺陷**（直接再拖一次即可）。

## 更新自动修复（三种方式可随时更换）

- **常驻守护（推荐）**：安装到 Startup 文件夹开机自启；检测是打开瞬间的实时检查，修复在你关闭启动器后几秒内完成；不碰桌面快捷方式，任务管理器可见可禁用（`wscript.exe`）。
- **启动壳检测**：无常驻进程，但必须用包内「启动PCL.vbs」打开启动器；绕过它直接双击原 exe 则不修复。
- **不自动修复（常规版）**：什么都不安装，更新后手动再拖一次。

更换方式：把 exe 再拖到「拖我上去.bat」选另一个选项即可；想改成不自动修复，用「拖我上去_常规版.bat」重打一次，它会自动移除之前的常驻守护。

> **补丁包文件夹请保留在原位置**：常驻守护要引用包内的 `Watch-PCL.vbs` 和 `Patcher.ps1`，移动或删除补丁包会让守护失效。

## 常见问题

**杀毒软件报毒 / 提示脚本被阻止？**
补丁通过 PowerShell 运行并修改 exe 文件，这类行为容易被启发式引擎误判。脚本全部开源可查，可自行审阅 `Patcher.ps1`。若系统拦截，可将补丁包目录加入信任，或临时对当前会话放开执行策略。

**补丁时提示文件被占用 / 写入失败？**
请先**完全关闭启动器**再打补丁。启动器运行中无法替换自身文件。

**某一项显示"未适配，跳过"？**
说明该版本的程序结构与补丁器已知结构不同，但**其余补丁项仍然生效**，MC 版本下载一般不受影响。如果下载页仍然打不开，可能是启动器版本变化较大，可到 [Issues](../../issues) 反馈。

**打完补丁后下载页还是空的？**
先确认启动器版本：旧版正式版本身没有限制，不需要补丁；如果确认是新版，请检查补丁输出里"MC版本下载恢复"一项是否为"成功"，并尝试完全退出启动器后重新打开。

**如何完整卸载？**
- 用 GUI：点「卸载补丁」，一键还原（需要包内原始备份还在）
- 手动：
  1. 删除 `Startup` 文件夹里的 `PCL自动修复.vbs`（移除开机自启守护）
  2. 用 `_原始备份\Plain Craft Launcher 2.exe` 覆盖回启动器
  3. 删除补丁包文件夹

若原始备份已被清理，也可以从官方渠道重新下载启动器覆盖。

## 注意事项

- 请勿分发打完补丁的启动器本体；要分享就分享本补丁包
- 快照版仅限赞助者自己使用，请勿转发快照版文件
- 正式版自动更新后限制会回来；选了自动修复无需操作，用常规版就把新 exe 再拖一次
- 补丁失败不会改动原文件；建议打补丁前手动备份一份 exe
- 打过补丁的补丁包目录会写入 `wrapper-path.txt`（含你本机启动器路径），分享补丁包前请先删除该文件与 `.lastpatched.sha256`

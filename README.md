# PCL Download Patch

恢复 PCL（Plain Craft Launcher）新版本中被关闭的 Minecraft 下载与整合包安装功能。

> 官方在新版启动器中关闭了 MC 下载与整合包安装（提示"为遵守相关法律法规……qwq"）。
> 本工具通过修改**你电脑上**的启动器文件来恢复这些功能——不包含、也不分发任何 PCL 程序代码或文件。

## 署名

- **补丁作者**：沐序 · [本项目仓库](https://github.com/AldricXZ/PCL-Download-Patch)
- **启动器原作者**：龙腾猫跃 LTCat · [爱发电](https://meloong.com/afd/a/LTCat)
- **PCL 官方发布页**：[meloong.com/pcl](https://meloong.com/pcl)

本仓库为第三方基于 PCL 的独立二次创作产物，与 PCL 官方无关联。

## 恢复的功能

- MC 版本下载：原版 / Forge / Fabric / OptiFine / NeoForge / LiteLoader 等
- 整合包安装：CurseForge / Modrinth（.mrpack）/ MCBBS / HMCL / MMC / 带启动器压缩包
- 版本修改页的 MC 选择卡片

## 使用方法

1. 从 [Releases](../../releases) 下载 `PCL下载补丁.zip` 并解压
2. 从官方渠道获取启动器：
   - 正式版（免费）：[meloong.com/pcl](https://meloong.com/pcl)
   - 快照版（赞助）：使用你自己的爱发电赞助账号下载
3. 建议先手动备份启动器：复制一份 `Plain Craft Launcher 2.exe` 改名保存（如 `Plain Craft Launcher 2_备份.exe`），出问题复制回来即可还原
4. 把 `Plain Craft Launcher 2.exe` 拖到下面任意一个 bat 上松手：
   - **「拖我上去.bat」**：按菜单选择更新后的自动修复方式——
     | 选项 | 方式 | 说明 |
     | --- | --- | --- |
     | 1 | 启动壳检测 | 以后用包内「启动游戏.vbs」启动游戏，启动前自动修复（无后台） |
     | 2 | 常驻守护（推荐） | 开机自启后台守护（约 15MB，无窗口），打开启动器时检测、关闭后自动修复 |
   - **「拖我上去_常规版.bat」**：只打补丁，不安装任何自动修复；更新后把新 exe 再拖一次
5. 重新打开启动器，进"下载"页确认版本列表能加载

## 谁需要打补丁

| 启动器 | 是否需要 |
| --- | --- |
| 新版正式版（官方已限制下载的构建） | 需要 |
| 快照版（赞助版） | 需要 |
| 旧版正式版（如 2.13.1.1，2026-07 构建） | 无限制，无需补丁 |

补丁器会自动判断；也支持**自动修复旧版本补丁包留下的已知缺陷**（直接再拖一次即可）。

## 更新自动修复（三种方式可随时更换）

- **常驻守护（推荐）**：安装到 Startup 文件夹开机自启；检测是打开瞬间的实时检查，修复在你关闭启动器后几秒内完成；不碰桌面快捷方式，任务管理器可见可禁用（`wscript.exe`）。
- **启动壳检测**：无常驻进程，但必须用包内「启动游戏.vbs」启动游戏；绕过它直接双击原 exe 则不修复。
- **不自动修复（常规版）**：什么都不安装，更新后手动再拖一次。
- 更换方式：把 exe 再拖到「拖我上去.bat」选另一项即可；切走时自动清理旧守护。

## 注意事项

- 请勿分发打完补丁的启动器本体；要分享就分享本补丁包
- 快照版仅限赞助者自己使用，请勿转发快照版文件
- 正式版自动更新后限制会回来；选了自动修复无需操作，用常规版就把新 exe 再拖一次
- 补丁失败不会改动原文件；建议打补丁前手动备份一份 exe
